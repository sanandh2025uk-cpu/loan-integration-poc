# Loan Integration PoC

Proof of Concept for a banking loan / leveraged finance integration solution.

## Technology Stack

- .NET
- ASP.NET Core Web API
- React
- TypeScript
- SQL Server
- Azure
- Git

## Purpose

This project is a learning and demonstration PoC covering:

- Loan application integration
- Customer and loan data
- REST APIs
- React frontend
- SQL Server
- AI-assisted banking capabilities
- Integration patterns
- Observability and monitoring
